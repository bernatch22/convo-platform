ms-1 · LLM in text reviewed by a human

Talk to the Clínica Norte receptionist from the terminal. Claude Haiku 4.5, prompt caching on, no STT/TTS, no server.

Try it

cp .env.example .env            # put ANTHROPIC_API_KEY in it
uv sync --extra dev
uv run python worker.py console --text      # Ctrl+T toggles text/mic (mic needs ms-6), Ctrl+C exits
uv run python worker.py console --text --record   # also saves console-recordings/session-*/session_report.json

Type in Spanish. Try: change an appointment, ask for a prescription, ask about cancellation fees, mention chest pain.

What exists

PathWhat it is
core/providers.pyThe only place that knows vendors: llm_for() = Haiku 4.5 with caching="ephemeral"; STT/TTS return None until ms-6. Supports identity-linked keys via ANTHROPIC_WORKSPACE_ID.
core/session.pybuild_session(tc): the LiveKit AgentSession for one TenantContext; turn detector disabled when there is no VAD (text sessions).
core/agents/base.pyTenantAgent: base of every stage; on_enter logs the stage and lets the model open the turn (the greeting).
core/registry.pyDiscovers tenants/*/tenant.py by folder, imports each in try/except (a broken tenant is unroutable, not fatal). No static import of tenants — the isolation test still holds.
core/router.pyresolve(ctx): dispatch metadata → TenantContext; console falls back to TENANT/PROJECT env. Pins the git SHA.
tenants/clinica-norte/…/prompts.pyThe reception prompt, shaped by Anthropic's current guidance: role sentence, long stable knowledge first (<clinic_knowledge>), instructions that explain why, five <example>s, prose not bullets.
…/knowledge.pyStable facts of the clinic (hours, floors, doctors, test preparation, prices, FAQ). Real reception content — and it keeps the cached prefix above Haiku's 4096-token floor.
…/agents.pyReception(TenantAgent): the single stage of ms-1, no tools.
tenants/_template/Copy to create a new customer (README with three steps).

A real conversation (session.run, the same path the console uses)

● Agent (greeting)
Buenas tardes, ¡bienvenido a Clínica Norte! Soy la recepción. ¿En qué puedo ayudarle hoy?
● You
hola, quiero cambiar mi cita del martes
● Agent ttft 0.80s
Claro, le ayudo con mucho gusto. ¿Me dice su nombre completo, por favor?
● You
me llamo Ana García, es el martes a las 10 con el doctor Navarro
● Agent ttft 0.66s
Perfecto, Ana. Le confirmo: cita del martes a las 10 de la mañana con el doctor Navarro de traumatología. ¿Qué día y franja horaria le vendría mejor?
● You
¿me podéis recetar algo para el dolor de cabeza?
● Agent ttft 0.69s
Entiendo, pero las recetas solo puede hacerlas un médico en consulta. Lo que sí puedo hacer es ofrecerle una cita con medicina de familia para que le valore y le prescriba lo que necesite. ¿Le vendría bien esta semana?
● You
vale, entonces mejor el jueves por la tarde si hay hueco
● Agent ttft 0.90s
Perfecto, Ana. Tomo nota de que prefiere el jueves por la tarde para cambiar su cita del martes a las 10 con traumatología. Voy a comprobar la disponibilidad y le llamaré hoy mismo en el mismo día laborable para confirmar la hora exacta. ¿Le parece bien?

Prompt caching — measured

system prompt: 4593 tokens   (Haiku 4.5 caches prefixes >= 4096 only; 3940 gave cache_creation=0)
session usage over 5 requests: input=23614  cache_creation=4850 (first turn)  cached=18667 (the other four)  output=300

Second turn onward reads the prefix from cache: cost per turn drops ~57% versus no cache.

What it took: the first prompt (~500 tokens) never cached; a realistic clinic knowledge block plus five examples pushed the stable prefix to 4593. The invariant is now in CLAUDE.md: every project prefix must exceed 4096 tokens and tests assert prompt_cached_tokens > 0.

What passed

pytest -m unit: 7 passed · ruff check + format: clean · no STT/TTS/VAD instantiated (assert s.stt is None and s.tts is None and s.vad is None) · 4-turn conversation coherent, on-topic, in Spain Spanish

Two things learned the hard way

anthropic SDK 1.x breaks livekit-plugins-anthropic 1.7 (it hands the client an httpx.AsyncClient, the new SDK wants httpx2) → pinned anthropic>=0.41,<1. The default TurnDetector needs a VAD → text-only sessions pass TurnHandlingOptions(turn_detection=None).

Open-source note

providers.py + session.py + TenantAgent are the reusable core; the tenant folder is the template others copy. The prompt shape (role → long knowledge → why-explained instructions → examples) is a pattern for any Claude voice agent, and the 4096-token caching floor is a gotcha worth sharing.

Known limits

No tools (ms-2), one stage (ms-3), no event log (ms-4), one tenant (ms-5), text only (ms-6). The agent says it "will call back" because it cannot see the agenda yet — by design.
