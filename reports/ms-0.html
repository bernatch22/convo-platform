Repo, toolchain, contracts, first tests. Nothing runs a conversation yet — that is ms-1.

What exists

PathWhat it is
worker.pyThe data plane: one AgentServer, one fleet (FLEET env, default cc). The entrypoint raises NotImplementedError until ms-1.
core/context.pyTenant, Project, TenantContext — the one object every session carries.
core/contracts.pySessionMeta: what the dispatcher tells the worker (tenant, project, channel). Unknown fields ignored on purpose.
core/tools/contract.pyToolSpec + SideEffect: irreversible tools always need a confirmation token; pii_scope says what to mask in logs.
core/adapters/base.pyAdapter port: capabilities() / execute(). Tenants implement it; tools never call HTTP directly.
core/state/events.pyEvent: one line of the append-only session log, numbered by seq.
tests/test_core_isolation (core never imports tenants) and test_contracts (the rules above hold).

Open-source note

The contracts are framework-agnostic: ToolSpec, Adapter and Event can be lifted into any voice-agent codebase (Pipecat, LiveKit, custom) as the seam between "what the LLM may call" and "what touches the customer's systems".

Continuous integration

.github/workflows/ci.yml runs ruff check, ruff format --check and pytest -m unit on every push with uv and Python 3.12. No provider keys are needed at this stage; the evals job arrives in ms-1 gated on secrets.

Known limits

No behaviour yet: no session, no providers, no tenants. python worker.py console starts and fails with the ms-0 message by design.
