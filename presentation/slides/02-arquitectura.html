02 · Entregable 1 — arquitectura de alto nivel

Tres planos, y una llamada es un proceso aislado

El plano de datos habla (worker.py), el de control decide y guarda (api.py), el de evidencia deja constancia. Un job no abre base de datos ni pool: todo el IO de negocio sale por HTTP, de modo que matar una llamada se lleva esa llamada y nada más. La alternativa —un worker con conexiones a la BD— ahorra un salto de red y a cambio deja que cualquier conversación corrompa el estado de todas. El LLM es un nodo dentro de una caja, no el marco del dibujo.

Validación. Los tres planos corren por separado hoy: python worker.py dev (datos), uvicorn api:app --port 8090 (control) y python -m convo sessions show AJ_rdrkYph3FaeS (evidencia). Esa sesión es una llamada PSTN real de 1 m 11 s y 88 eventos: el job que la atendió no abrió ninguna conexión a base de datos — core/control_plane.py es lo único que sostiene un handle.
