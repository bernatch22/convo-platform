# ms-13 — voice evals: callers who really speak, nights that really judge, and a model that talks back

**What we set out to do.** Ring 2: synthetic callers over real audio, personas,
a nightly against the deployed fleet. **What the chapter became** is bigger —
it grew ring 4 (every call scores itself) and, in the process of making judges
cheap and constant, it forced three model-behavior findings that changed how
the platform talks to its own LLM.

## What shipped

**Ring 2 — a caller who really speaks.** `POST /evals/rooms` mints a room with
the same dispatch metadata the JWT road carries; `converse()` plays persona
audio through a virtual microphone and collects the agent's real STT-heard,
TTS-spoken replies with per-turn latencies. Two personas as data: `apurado`
(interrupts — 7 barge-ins per call exercised) and `spanglish` (es↔en
mid-sentence — a Spanish-only transcript now fails the run). The design
decision that matters: **each live call is two cases** — the wire transcript
(flaky, judged for register/leakage) and the same call rebuilt from its event
log (judged for consent), because a synthetic caller hears what was said and
nothing that was done; scored off the wire alone, consent would pass
vacuously.

**The nightly — red means red, which had to be earned.** A systemd timer
(04:00 Europe/Madrid, `Persistent=false` because a unit that spends provider
money must not decide to spend it at noon after a reboot) runs whole suites
under an 8-call cap — never trimmed: half a suite scores half a policy. The
first forced-regression drill FAILED SILENTLY: `flaky=True` (correct for wire
cases) means DeepEval exits 0 over a 0.00 metric, so the nightly reported a
green night over a broken register. Status is now read off the scores; the
second drill proved the chain (unit failed, HTML red with transcript, console
row at delta −1.0).

**Ring 4 — every call scores itself.** A sweeper in api.py POLLS for
finished-and-unscored sessions — a poll, not a callback, because a SIGKILLed
job never gets to say it is gone and that is exactly the call whose score
matters. Four checks decided by code (consent, register, leakage, provider
errors — imported from the ring-1 definitions, not reimplemented) plus at
most ONE Haiku judge, priced against the same table `session.end` bills with
BEFORE the call is made. Measured: **0.14 cents per scored call, 0 for a
hang-up.** The verdict is a `session.score` event with the next `seq`; the
console shows a chip, `convo sessions show` prints the rows, a project can
opt out and shows a dash.

## The three model-behavior findings — each one measured, each one landed

1. **The phantom turn.** Soniox hallucinates a final ("Thank you.") over PSTN
   comfort noise, and the framework starts a turn on the transcript's say-so —
   the VAD is never consulted. The fix is an energy gate against the line's
   own noise floor (never a phrase blocklist), and its golden carries a
   CONTROL: the same script with the gate off reproduces the bug.
2. **The date arrived as the caller's first sentence.** Not the plugin — one
   layer up, `convert_mid_conversation_instructions` rewrites every non-first
   system item into a user-role `<instructions>` message. Haiku answered the
   note as a person 5/6. The fix: the session opens with a paired
   `fecha_y_hora_actual` tool call + result — a tool result is evidence, not
   speech (0/6 answered) — position kept, cached prefix untouched.
3. **The whisper would not bind.** A steer is not a date note: a tool result
   is read and filed, not obeyed (1/3), and against a stage script every
   delivery failed 0/3 — until the CACHED PREFIX taught the persona that
   supervisor instructions exist and outrank its script (`SUPERVISOR_PROTOCOL`,
   stable text, cache-safe): 3/3. "Say this now" belongs honestly to
   `inject_and_speak`. ~70 live runs, ~$0.40, the table in docs/evals.md §9.
   The steer goldens are green four runs straight — including the one that
   matters most: an unverified steer changes nothing and leaks nothing.

Also in the chapter: the phone number stopped being a fleet-wide lie — it is
store data per project now (the routes table the router already read, seeded),
and the console shows each project's line or its honest absence.

## Where evals stand

Four rings, one vocabulary: per-golden text (CI + the console's Run button),
live voice (nightly), stored real sessions (on demand), and every call
automatically at 0.14 cents. The judges keep getting cheaper and the
deterministic share keeps growing — and the chapter's real lesson is that the
eval rings are not quality theater: **every finding above was caught by a
ring doing its job**, and each fix shipped with the golden that would catch
its regression.

**Honest gaps.** The milestone's original criteria named p50/p95 e2e + WER in
the nightly scores (latencies ride the transcripts; WER and percentile rollups
are not computed) and auto-promotion of a failing real session to a golden
(not built — `convo sessions eval` is the manual half). Both are real
follow-ups, neither blocks the chapter's substance.
