# ms-10 — box core on GCP: the platform answers from the cloud

**What we set out to do.** Move the whole runtime — SFU, SIP, worker, control
plane, console — onto one public VM so a phone call from anywhere reaches our
agent, and the console that tunes it is a URL, not a laptop.

**What we achieved.** The box (4 vCPU / 16 GB, static IP) runs livekit-server,
livekit-sip, redis and caddy under compose, with `convo-worker` and `convo-api`
as systemd units beside them. A call to +1 417 674 3169 rings into the cloud
worker with a warm greeting that costs nothing (pre-synthesized). The console
lives at https://lk.bernardocastro.dev, in light or dark. Both providers of the
two expensive legs are now **slots switchable from the console with no deploy**:
STT (Soniox ↔ Deepgram Flux) and LLM (Haiku ↔ gpt-5.4-mini). WebRTC was
verified from a real mobile network (3G) with no dedicated TURN deploy.

## The decisions, and why

**One domain, not two.** The first plan had `lk.` for the SFU and `app.` for
the console. But two subdomains meant two stores: the public UI would have
written a config database the phone worker never read. Caddy settles it —
`/rtc*`, `/twirp*` and WebSocket upgrades go to livekit-server:7880, everything
else to api.py:8090, one TLS cert, one origin. `core/auth.py:public_url()`
hands browsers `wss://lk.bernardocastro.dev` while the worker keeps loopback.

**The store is the dev/prod seam.** api.py shares the worker's
WorkingDirectory, so one `tmp/convo.db` serves both. A PUT from the public
console lands in the row the next phone call resolves. That one sentence is
the whole "dev vs prod" story: there is no promotion step, the store is live.

**Preemptive generation OFF — by measurement, not fashion.** With the local
turn detector confirming end-of-turn in ~0.33 s, speculative generation never
hid Haiku's time-to-first-token; it only spent aborted calls. Decision recorded
in CLAUDE.md; generation starts on confirmed end of turn.

**Postgres deferred.** SQLite under WAL serves one writer (api.py) and one
reader (the worker's control-plane HTTP) without contention at this load. The
trigger to migrate is written down: a second box, or any second process that
writes. Migrating earlier would have been ceremony.

**TURN deferred — by evidence.** The acceptance test was a call from a hostile
network; the human placed it over 3G and it worked (UDP media reached the SFU
directly; 443 is already Caddy's). What production still wants, recorded on
tk-bc2d5d: a TURN/TLS listener for networks that block UDP outright
(corporate wifi, some hotel NATs).

## Learned the hard way

- **Deepgram Flux: `flux-general-en` 400s on a `language_hint`.** The
  multilingual model is `flux-general-multi` via the plugin's `STTv2`
  (`/v2/listen`), not `STT`. Found by reading the plugin source, not the docs.
- **gpt-5.4-mini wants `max_completion_tokens`** (not `max_tokens`) **and
  `reasoning_effort="none"`** — the latter pinned by test, because a plugin
  bump that re-enables reasoning silently adds ~400 ms per turn.
- **A stale invariant died:** our CLAUDE.md demanded `sanitize_tool_pairing()`
  before every generation. livekit-agents 1.7.1 already guards orphan
  `tool_use` one layer below us (`group_tool_calls` /
  `remove_invalid_tool_calls`), provider-independent. The invariant was
  reworded to describe the framework's guarantee instead of prescribing a
  function we never wrote.
- **The SIP fraud night** (full story in `security.md`): 5060/udp open to the
  world was flooded within hours, and livekit-sip's anti-flood then 486'd real
  calls; on GCP, removing an allow rule does **not** kill established UDP flows
  — an explicit DENY is required. Same night, our own trunk automation
  pattern-matched Twilio's account-takeover heuristics and got the account
  suspended. SIP signalling now only accepts the carrier's published CIDRs.

## Cost per call — real sessions, from the event log

Every `session.end` carries the euros at that day's rate (`core/observability/
prices.py`; the log is the audited fact, repricing never rewrites it). Real
sessions from 2026-08-30/31, clinica-norte/reagendamiento:

| session | channel | events | LLM | EUR |
|---|---|---|---|---|
| AJ_rt86Kog | voice (PSTN) | 41 | claude-haiku-4-5 | 0.0106 |
| AJ_u8tCU7U | chat | 17 | claude-haiku-4-5 | 0.0087 |
| AJ_Vwx8S2F | voice (web) | 24 | claude-haiku-4-5 | 0.0086 |
| AJ_45VwRr4 | voice (PSTN) | 10 | claude-haiku-4-5 | 0.0078 |
| AJ_x6YPBv7 | voice (PSTN) | 35 | claude-haiku-4-5 | 0.0050 |
| AJ_AKu49Ru | voice (PSTN) | 25 | claude-haiku-4-5 | 0.0017 |

Call it **~0.5–1 euro cent of LLM per short call**. Soniox and ElevenLabs are
priced at 0 in the table deliberately: they bill per minute on plan rates, not
per token, and a made-up per-token number would be a lie in an audited log —
their per-minute rates belong in REPORT §11's totals, not here. Twilio's PSTN
leg (~$0.0085/min inbound) dominates the marginal cost of a phone call.
